# Dataset

The LendingClub loan dataset used in this project was obtained from Kaggle.

The original dataset contains approximately 2.26 million loan records and
151 features.

The raw dataset is not included in this GitHub repository because of its
large size. The notebooks contain the code used to clean and preprocess
the dataset.

To reproduce the project, download the LendingClub dataset from Kaggle
and place the required CSV file inside this `data/` directory.
